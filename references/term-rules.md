# 中英文处理规则

本技能的核心规则，必须严格执行。

1. 正文、标题、图注一律使用中文；专业术语按下列规则处理。

2. 有稳定中译的术语，首现写“中译（English）”，之后只用中译。
   例如：注意力机制（attention）、消融实验（ablation）。

3. 无公认中译或圈内默认用英文的术语，保留英文原文，不强行翻译。
   例如：Transformer、LoRA、prompt、token。

4. 模型名、数据集名、指标名、框架名一律保留英文原样。
   例如：ResNet-50、ImageNet、mAP、F1、BLEU。

5. 缩略语首次出现时给出全称。
   例如：Transformer 中的 RNN（Recurrent Neural Network）。

6. 引用原文关键论断时，若涉及术语歧义，可括注英文原句片段，但不整段照抄英文。

7. 禁止：使用生硬直译、自创译名、对同一术语前后译法不一致。
